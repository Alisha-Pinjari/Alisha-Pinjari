**Machine Learning | Predictive Modeling | Classification**

- Developed an ML-based system to classify insurance claims as fraudulent or legitimate.
- Performed EDA, data preprocessing, feature engineering, and class imbalance handling.
- Implemented Logistic Regression, Random Forest, and XGBoost.
- Compared model performance and identified XGBoost as the best-performing algorithm.
- Evaluated models using classification metrics.

**Tech Stack:** Python, Pandas, Scikit-learn, XGBoost

### 💬 2. RAG-Based AI Chatbot
**Generative AI | RAG | LLMs | Semantic Search**

- Developed a document-based question-answering chatbot using RAG architecture.
- Implemented document chunking using Recursive Character Text Splitting.
- Generated vector embeddings using all-MiniLM-L6-v2 Sentence Transformers.
- Integrated FAISS for similarity-based document retrieval.
- Used LangChain and Groq LLM API for context-aware response generation.
- Built an interactive Streamlit application.

**Tech Stack:** Python, LangChain, FAISS, Sentence Transformers, Groq LLM API, Streamlit
